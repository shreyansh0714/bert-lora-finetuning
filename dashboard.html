Full fine-tuning vs LoRA

We taught a ready-made language model (Google's BERT) to sort bank customers' messages into 77 categories, such as “card lost” or “refund not showing”. We tried two ways of teaching it, and measured how accurate each one is and how much it costs. Every table, chart and highlighted figure is read straight from the result files in results/; only the section introductions describe the training setup in words.

github.com/shreyansh0714/bert-lora-finetuning

Key words, in plain English

Model (BERT)
A pre-trained language model: about 110 million adjustable numbers, called parameters, that already understand English.
Full fine-tuning
Teach the new task by adjusting all 110 million numbers. Accurate, but it needs a lot of memory, and every task needs its own full copy of the model.
LoRA
Freeze the model and train only a small add-on next to it. Far fewer numbers to adjust and far less to store.
Size of the add-on (rank, r)
How big the LoRA add-on is. Doubling r roughly doubles the add-on.
Pass (epoch)
One full pass through all the training examples. More passes means more practice.
Test accuracy
The share of 3,080 messages the model had never seen that it puts in the right category.

Stage 1 — Two ways of teaching the model

Arnav's part (notebooks/01_baseline_full_finetune_vs_lora.ipynb). The same model and the same data, taught both ways. Each had a cap on passes and could stop early once it stopped getting better; in this run both used every pass they were allowed (10 and 20).

Stage 1 — How fast each method learned

Accuracy after each pass through the data. Full fine-tuning levels off early. LoRA is still creeping up near the end of its 20 passes (its best was pass 19), so its score is a floor, not its best possible.

Stage 2, Run 1 — LoRA at four sizes, 4 passes each

Our first attempt (notebooks/archive/02_lora_rank_sweep_4ep.ipynb). To find out how big the add-on needs to be, we trained it at four sizes, giving each size only 4 passes through the data, with no warm-up and no early stopping.

Stage 2, Run 2 — the same four sizes, a better training setup

Same sizes and learning rate (notebooks/02_lora_rank_sweep.ipynb). The training setup changed in five ways: up to 20 passes instead of 4; a gentle warm-up of the learning rate at the start; early stopping that keeps the best checkpoint; 10% of the training data held back as a practice-check set (9,002 training rows instead of 10,003); and the per-pass check done on that set instead of on the test messages.

Run 1 vs Run 2

Both runs on one chart. The gap between the two lines is what the better training setup bought. The slope along each line is what a bigger add-on bought.
